## 재현 방법
```bash
# (사전) 소스 정규화: EXIF 회전 반영해 _build/src/*.jpg 생성 (포트레이트 9매 등)
# 렌더: 27개 세그먼트 → xfade 연결 → video_noaudio.mp4
python render.py            # 전체
python render.py 05         # 특정 세그먼트만 미리보기
FORCE=05,26 python render.py  # 일부 강제 재렌더

# 음악 생성 (영상 길이에 맞춰 초 지정)
python music.py 176         # bgm.wav 생성

# 최종 합성 (ffmpeg-static 사용)
ffmpeg -i video_noaudio.mp4 -i bgm.wav \
  -filter_complex "[1:a]afade=t=in:st=0:d=3,afade=t=out:st=171.3:d=2.8,volume=0.9[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -shortest -t 174.1 -movflags +faststart out.mp4
```
- `render.py`: 세그먼트 정의(소스/길이/줌/자막), 켄번즈·블러배경·클립 처리, xfade 체인
- `music.py`: 오리지널 CCM풍 BGM 합성(numpy)
- `txt/*.txt`: 자막 원문(UTF-8). drawtext `textfile=`로 burn-in
- 도구: `node_modules/ffmpeg-static/ffmpeg.exe`(repo), Python+Pillow, 폰트 Malgun Gothic Bold
